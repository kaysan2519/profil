### ✦ About Me

I am a passionate **Full-Stack Software Engineer** and **Frontend Specialist** with a deep enthusiasm for building high-performance web systems, intuitive user experiences, and scalable software architectures.

- 🔭 **Current Focus:** Engineering full-stack web applications with modern **TypeScript**, **Next.js (App Router)**, **React 19**, and robust ORMs like **Prisma** and **Drizzle**.
- 💡 **Engineering Philosophy:** Clean code, modular architecture, type safety from database to UI, and meticulous attention to user experience design.
- 📱 **Cross-Platform:** Crafting responsive web apps and cross-platform mobile solutions with **Flutter & Dart**.
- 🌱 **Continuous Growth:** Exploring distributed backend workflows, advanced state management, and modern frontend rendering optimizations.
- 🎯 **Goal:** Building resilient, production-ready software solutions that deliver genuine value and memorable user experiences.
